# 日报说明与模板

## 提交要求

1. **每人每个工作日一份**，当天 18:00 前提交。
2. 文件命名：`YYYYMMDD-姓名.md`，例：`20260727-张三.md`。
3. 存放于本目录（`reports/daily/`），直接复制下方模板填写。
4. 内容必须真实、具体：写清做了什么、卡在哪、明天干什么。禁止只写"写代码""继续开发"这类空话。
5. 日报与 Git 提交记录会交叉核对，作为个人考核依据。

## 写好日报的标准

- ✅ 好的写法："完成商品列表接口的分页查询，联调时发现分类筛选参数传空串会报 500，已定位是未做空值判断，明天修复"
- ❌ 差的写法："今天写了后端代码，明天继续"

# 周报说明与模板

## 提交要求

1. **每组每周一份**，由组长汇总，周五 18:00 前提交。
2. 文件命名：`第N周-周报.md`，例：`第1周-周报.md`（共 4 篇）。
3. 存放于本目录（`reports/weekly/`），复制下方模板填写。
4. 周报内容须与各成员日报、Git 提交记录一致。

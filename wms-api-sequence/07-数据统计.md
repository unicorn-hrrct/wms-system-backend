## 7. 数据统计（第十一章）

### 7.1 场景：库存仪表盘

```
Client → GET /api/dashboard/stock
       → DashboardController → DashboardService
       │
       ├─ ① totalSkuCount: SELECT COUNT(*) FROM pro_sku WHERE deleted=0
       ├─ ② totalStockValue: SUM(s.quantity * sku.purchase_price) FROM sto_stock JOIN pro_sku
       ├─ ③ lowStockCount: 子查询（参考 9.5）
       ├─ ④ outOfStockCount: SUM(quantity)=0
       ├─ ⑤ todayInboundCount / todayOutboundCount: sto_stock_log WHERE operate_time::date = CURRENT_DATE AND type IN (1,2)
       ├─ ⑥ topStockProducts: GROUP BY sku ORDER BY SUM(quantity) DESC LIMIT 10
       └─ ⑦ recentTrend: 最近 7 天按天聚合
```

**性能要点**：仪表盘数据量大，应使用 **Redis 缓存**（5分钟过期）+ 异步刷新。

### 7.2 场景：销售报表

```
Client → GET /api/report/sales?startDate=&endDate=&granularity=day|week|month
       → ReportService
       │
       ├─ ① 按 granularity 切时间桶：
       │    day:   date_trunc('day', pay_time)
       │    week:  date_trunc('week', pay_time)
       │    month: date_trunc('month', pay_time)
       ├─ ② 聚合：SUM(pay_amount), COUNT(order_id), AVG(pay_amount)
       ├─ ③ topProducts: JOIN ord_order_item，GROUP BY sku_id ORDER BY SUM(quantity) DESC
       ├─ ④ categoryDistribution: JOIN pro_category 按分类汇总
       └─ ⑤ 返回
```

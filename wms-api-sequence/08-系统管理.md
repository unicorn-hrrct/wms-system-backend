## 8. 系统管理（第十二章）

### 8.1 场景：操作日志

```
AOP 拦截 @RestController 调用
       → sys_oper_log INSERT（username, module, operation, ip, status, errorMsg）
       → 异步线程池（避免阻塞业务）

GET /api/log/operation?username=&module=&startDate=&endDate=
       → 分页查询 sys_oper_log
```

**实现要点**：用 `@Around` 切面 + `ThreadPoolTaskExecutor` 异步写入；敏感接口记录 `requestBody`。

### 8.2 场景：字典查询

```
Client → GET /api/dict/type/{dictType}
       → DictService
       └─ SELECT * FROM sys_dict_data WHERE dict_type=? AND status=0 ORDER BY sort_order
```

**常用字典**：`sys_order_status`、`sys_pay_type`、`sys_warehouse_type`、`sys_stock_alert_type`、`sys_aftersale_type`。

### 8.3 接口路径速查（第十二章）

| 接口 | 实现 |
|------|------|
| `GET /api/log/operation` | AOP 自动收集 |
| `GET /api/dict/type/{dictType}` | sys_dict_data |
| `GET /api/config/list` | sys_config（可缓存） |

## 3. 供应商与客户管理（第七章）

### 3.1 场景：供应商 CRUD

```
Client → POST /api/supplier {supplierName, contactPerson, ...}
       → SupplierService
       ├─ ① 同名校验
       └─ ② INSERT sup_supplier

Client → GET /api/supplier/list?name=&status=&pageNo=1
       → SupplierService.page(queryWrapper.eq('status', ...).like('name', ...))
```

**状态变化**：`status=0` 合作中，`status=1` 已停用；停用后不能再被采购申请引用。

### 3.2 场景：用户地址簿

```
Client → GET /api/address/list
       → AddressController → AddressService
       ├─ ① SELECT * FROM ord_address WHERE user_id = currentUserId AND deleted=0
       └─ ② 按 is_default DESC, create_time DESC 排序

Client → POST /api/address {isDefault:true, ...}
       → AddressService
       ├─ ① 若 isDefault=true：
       │    UPDATE ord_address SET is_default=false WHERE user_id=?
       │    （同一用户只能有一个默认地址）
       └─ ② INSERT ord_address
```

**实现要点**：单用户唯一默认地址要放在**事务**里，避免中间状态出现两条默认。

## 10. 端到端三大闭环（一图流）

### 10.1 采购 → 库存 闭环

```
[采购员] 提交申请                [管理员] 审核           [仓管] 入库           [仓管] 退货
POST /purchase/request  ──▶  PUT /purchase/request/{id}/audit  ──▶  POST /purchase/inbound  ──▶  POST /purchase/return
        │                          │                          │                          │
        ▼                          ▼                          ▼                          ▼
pur_request.status=0       pur_request.status=1|2       sto_stock.quantity+=       sto_stock.quantity-=
INSERT pur_request_item    (驳回则终止)                  INSERT sto_stock_log       INSERT sto_stock_log(type=2)

                                   │                          │
                                   ▼                          ▼
                            POST /purchase/order          pur_order.status
                            INSERT pur_order              0→1→2 推进
```

### 10.2 销售 → 库存 闭环（核心：含 Redis 锁）

```
[用户] 加车                [用户] 下单                          [用户] 支付              [管理员] 发货    [用户] 收货
POST /cart/add  ──▶  POST /order/create  ──▶  POST /order/{id}/pay  ──▶  POST /order/{id}/ship  ──▶  PUT /order/{id}/receive
        │                       │                       │                       │                       │
        ▼                       ▼                       ▼                       ▼                       ▼
ord_cart UPSERT          ① Redis Lua 锁扣减       ord_order.status=1      ord_order.status=2      ord_order.status=3
                         ② DB UPDATE sto_stock    Redis 锁 confirm         发货单
                            SET quantity-=n,         DB: locked_quantity-=n
                            locked_quantity+=n   ③ MQ: order.paid
                         ③ INSERT ord_order
                            status=0, expire=30min
                         ④ MQ: order.created
                         ⑤ DELETE ord_cart

                                              取消旁路
                                              ──────────────────────▶
                                              PUT /order/{id}/cancel
                                                  │
                                                  ▼
                                              ord_order.status=4
                                              Redis 锁 cancel / DB 回滚 quantity
                                              MQ: order.cancelled
```

### 10.3 库存预警 → 补货 闭环

```
定时 @Scheduled(cron="0 0 2 * * ?")
        │
        ▼
RestockService.generateSuggestions()
        │
        ├─ 算日均销量（最近30天）
        ├─ 算可用库存
        ├─ INSERT res_restock_suggestion
        └─ MQ: stock.alert

[采购员] GET /advanced/restock/suggestion
        │
        ▼
[采购员] POST /advanced/restock/generate-order {suggestionIds}
        │
        ▼
按 supplierId 自动合并生成多张 pur_request（status=0）
        │
        ▼
走标准采购流程（4.1~4.4）
```

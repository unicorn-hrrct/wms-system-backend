## 11. 部署与调试速查（第十四章）

### 11.1 本地启动 6 步走

```bash
# 1) 启动 PostgreSQL 18
# 2) 启动 Redis（进阶模块需要）
"C:\Program Files\Redis\redis-server.exe"

# 3) 初始化数据库
set PGPASSWORD=postgres密码
"C:\Program Files\PostgreSQL\18\bin\psql.exe" -U postgres -h localhost -p 5432 -f sql/setup.sql

# 4) 切换 UTF-8 避免乱码
chcp 65001

# 5) 启动应用
cd C:\Users\unicorn\Desktop\wms-system
mvn spring-boot:run

# 6) 验证
curl -X POST http://localhost:8080/api/auth/login -H "Content-Type: application/json" -d '{"username":"warehouse","password":"warehouse123"}'
```

### 11.2 调试常见问题速查

| 现象 | 根因 | 解法 |
|------|------|------|
| 401 Unauthorized | Token 缺失/过期/签名错 | 检查 `Authorization: Bearer ` 前缀，secret 长度 ≥256 位 |
| 分页查询返回全表 | 没引入 `mybatis-plus-jsqlparser` | pom.xml 加该依赖 |
| 中文乱码 | Windows GBK | `chcp 65001` |
| 启动报 `ClassNotFoundException: spring-boot-starter-web` | Spring Boot 4 改了 artifactId | 改用 `spring-boot-starter-webmvc` |
| Redis Lua 报 NOSCRIPT | Redis 重启清空了脚本 | 用 `SCRIPT LOAD` 预加载或每次 EVAL |
| 下单并发超卖 | 没加行级锁/条件更新 | `WHERE (quantity-locked_quantity) >= ?` 影响行数校验 |
| MQ 消息丢失 | 业务事务先提交后 MQ 失败 | 用本地消息表 + 定时扫描补偿 |
| 库存不准 | 库存流水和库存变更不在同事务 | 强制 `@Transactional` 包住两者 |

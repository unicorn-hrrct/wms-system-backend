## 关键设计点速览

- **下单防超卖**：Redis Lua + DB `WHERE (quantity-locked_quantity) >= ?` 条件更新双重保险
- **库存变更 + 流水**：强制 `@Transactional` 同事务
- **MQ 一致性**：本地消息表 + 定时扫描补偿（防止 DB 已提交但 MQ 失败）
- **盘点并发**：抽盘用 `SELECT FOR UPDATE` 锁行；全盘走差异暂存
- **JWT 鉴权矩阵**：6 种 Token 状态 × HTTP × 业务码的对应关系

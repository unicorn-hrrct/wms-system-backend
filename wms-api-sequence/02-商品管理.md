## 2. 商品管理（第六章）

### 2.1 场景：分类树初始化

```
Client → GET /api/category/tree
       → CategoryController → CategoryService
       │
       ├─ ① SELECT * FROM pro_category WHERE deleted=0
       ├─ ② 在内存中按 parent_id 组装树（一次性全量加载，量级<1000）
       └─ ③ 返回递归 VO
```

**实现要点**：分类量小直接内存递归；量大要改成邻接表 + 缓存。

### 2.2 场景：新增商品（SPU + 多 SKU 一次性创建）

```
Client → POST /api/product
       → ProductController → ProductService
       │
       ├─ ① 校验 productCode 唯一（sys_user.UNIQUE 类）
       ├─ ② 校验 categoryId 存在
       ├─ ③ @Transactional 开始
       │    ├─ INSERT pro_product
       │    ├─ 遍历 skuList：
       │    │    ├─ 校验 skuCode 唯一
       │    │    ├─ specValues 转 JSONB 字符串（Jackson）
       │    │    └─ INSERT pro_sku（product_id 关联）
       │    └─ 提交事务
       └─ ④ 返回 {productId, productCode, skuCount}
```

**状态变化**：`pro_product.status=0`（上架），`pro_sku` 多条同 `product_id`。

**异常分支**：SKU 编码重复 → 整事务回滚；JSONB 序列化失败 → 抛 `BusinessException`。

### 2.3 场景：商品上下架

```
Client → PUT /api/product/{id}/status {status:0|1}
       → ProductController → ProductService
       │
       ├─ ① 校验商品存在
       ├─ ② UPDATE pro_product SET status=? WHERE id=?
       └─ ③ (可选) 同步更新 pro_sku 状态
```

**实现要点**：下架时若有未支付订单引用，是否允许？建议**只影响前台检索**，不影响后台库存和已有订单。

### 2.4 场景：前台购物端搜索

```
Client → GET /api/shop/product/search?keyword=...&sortBy=sales&sortOrder=desc
       → ShopController（permitAll 但建议带 token 拿个性化推荐）
       → ProductService.searchShop()
       │
       ├─ ① 拼装 QueryWrapper（status=0 上架, keyword LIKE）
       ├─ ② 关联 pro_category 拿 categoryName
       ├─ ③ 排序：sales 需 SUM(order_item.quantity)；newest 用 create_time
       ├─ ④ PaginationInnerInterceptor 分页
       └─ ⑤ 返回 { total, list:[...] }
```

**性能要点**：
- `keyword` 搜索建议用 PG 的 `to_tsvector('simple', product_name)` + GIN 索引
- `sales` 排序必须走物化视图或预计算字段，不要每次 ORDER BY SUM

### 2.5 接口路径速查（第六章）

| 接口 | 鉴权 | 备注 |
|------|------|------|
| `GET  /api/category/tree` | 需 Token | 递归树 |
| `POST /api/category` | 需 Token | 单条新增 |
| `GET  /api/product/list` | 需 Token | 后台分页+搜索 |
| `POST /api/product` | 需 Token | SPU+SKU 事务 |
| `PUT  /api/product/{id}` | 需 Token | 同上结构（部分更新） |
| `PUT  /api/product/{id}/status` | 需 Token | 上下架 |
| `GET  /api/product/{id}` | 需 Token | 详情含 SKU |
| `DELETE /api/product/{id}` | 需 Token | 逻辑删除 deleted=1 |
| `GET  /api/shop/product/search` | 放行/带 Token | 前台搜索 |

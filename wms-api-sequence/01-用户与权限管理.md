## 1. 用户与权限管理（第五章）

### 1.1 场景：首次登录获取 Token

```
Client                AuthController      AuthenticationManager   UserDetailsServiceImpl   JwtUtil
  │                       │                       │                       │                  │
  │ POST /api/auth/login  │                       │                       │                  │
  │ {username,password}   │                       │                       │                  │
  │──────────────────────▶│                       │                       │                  │
  │                       │ authenticate(token)   │                       │                  │
  │                       │──────────────────────▶│                       │                  │
  │                       │                       │ loadUserByUsername()  │                  │
  │                       │                       │──────────────────────▶│                  │
  │                       │                       │   查 sys_user, sys_user_role             │
  │                       │                       │   校验 BCrypt 密码                       │
  │                       │                       │   返回 UserDetails(含 authorities)       │
  │                       │                       │◀──────────────────────│                  │
  │                       │ roles=[]              │                       │                  │
  │                       │◀──────────────────────│                       │                  │
  │                       │ generateToken(uid, uname, roles)                                    │
  │                       │──────────────────────────────────────────────────────────────────▶│
  │                       │   HS256 签名, sub=uid, claim=username/roles, exp=now+24h           │
  │                       │◀──────────────────────────────────────────────────────────────────│
  │ {code:200, data:{token, userId, roles, expireTime}}                                         │
  │◀──────────────────────│                                                                       │
```

**状态变化**：`sys_user.status` 必须为 `0`（正常）才能登录；`status=1` 在 `UserDetailsServiceImpl` 抛 `BadCredentialsException`。

**异常分支**：
- 用户不存在 → `401 用户名或密码错误`（不暴露具体原因，防爆破）
- 密码错误 → 同上
- 用户禁用 → 同上（避免泄露账号状态）

**实现要点**：
- 密码 BCrypt：`PasswordEncoder.encode(raw)` → `$2a$10$...`，登录时 `matches(raw, hashed)`
- Token 中只放 `userId / username / roles`，不放权限点；权限在登录后按需查菜单接口
- 不要在 Controller 内捕获 Authentication 异常，统一交给 Security 的 `AuthenticationFailureHandler`

### 1.2 场景：注册新用户

```
Client → POST /api/auth/register → UserController → UserService
                                    │
                                    ├─ ① 校验 username 唯一（sys_user.UNIQUE）
                                    ├─ ② BCrypt 加密 password
                                    ├─ ③ INSERT sys_user
                                    ├─ ④ 默认绑定 sys_role.user（普通用户）
                                    └─ ⑤ INSERT sys_user_role
```

**状态变化**：`sys_user` 新增一行；`sys_user_role` 新增一行（user+role）。

**异常分支**：username 重复 → `400 用户名已存在`。

### 1.3 场景：访问受保护接口

```
Client ──GET /api/user/info──▶ JwtFilter ──▶ AuthController(/api/user/info)
   ▲                              │                │
   │                              ▼                ▼
   │                          SecurityContext   UserService.getByUsername
   │                              │                │
   │                              ▼                ▼
   │                          Controller 内部    sys_user + sys_role JOIN
   │                              │                │
   │◀─{code:200, data:{userId,roles,permissions}} ─┘
```

### 1.4 场景：修改密码

```
Client → PUT /api/user/password {oldPassword, newPassword}
       → UserController → UserService
       │
       ├─ ① BCrypt.matches(oldPassword, user.password)
       ├─ ② 校验 newPassword 长度 6-20
       ├─ ③ BCrypt.encode(newPassword)
       └─ ④ UPDATE sys_user SET password=? WHERE id=currentUser.id
```

**异常分支**：旧密码错 → `400 原密码错误`；新密码不合规 → `400 密码长度6-20`。

### 1.5 接口路径速查（第五章）

| 接口 | 鉴权 | 关键点 |
|------|------|--------|
| `POST /api/auth/login` | 放行 | 返回 token |
| `POST /api/auth/register` | 放行 | 默认 user 角色 |
| `GET  /api/user/info` | 需 Token | 当前登录用户 |
| `PUT  /api/user/password` | 需 Token | BCrypt 双重校验 |
| `GET  /api/role/list` | 需 Token | 全量角色 |
| `GET  /api/menu/tree` | 需 Token | 按角色过滤 |

## 12. 附录：错误码速查

| 业务码 | 含义 | 触发场景 |
|--------|------|----------|
| 200 | 成功 | — |
| 400 | 参数错误 | 字段校验失败 |
| 401 | 未登录/Token过期/无效 | JwtFilter 拒绝 |
| 403 | 无权限 | SecurityConfig 拒绝 |
| 404 | 资源不存在 | 查询为空 |
| 500 | 服务器内部错误 | 未捕获异常 |
| 50001 | 库存不足 | 9.5 / 13.1 |
| 50002 | 库存扣减失败（并发冲突） | 9.5 / 13.1 |
| 50003 | 订单状态异常 | 6.4 取消/支付校验 |
| 50004 | 支付超时/失败 | 6.3 |
